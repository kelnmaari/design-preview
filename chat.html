Good instinct — single-responsibility will make each piece testable in isolation. Here's a clean three-layer split:

// 1. Extraction — pulls the raw token from the request
func extractToken(r *http.Request) (string, error) {
    auth := r.Header.Get("Authorization")
    if !strings.HasPrefix(auth, "Bearer ") {
        return "", ErrNoToken
    }
    return strings.TrimPrefix(auth, "Bearer "), nil
}

The key insight: each function returns an error, so the middleware becomes a short pipeline where any stage can short-circuit with a typed error. Want me to sketch the verifier and loader layers too?
